## Usage

Все цвета определены как CSS переменные в файле `src/styles/colors.scss` и могут быть использованы в компонентах через `var(--color-name)`.

Пример:

```scss
.button {
  background-color: var(--color-primary);
  color: var(--color-white);
}
```
